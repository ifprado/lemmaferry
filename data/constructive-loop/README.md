# Cumulative constructive-library examples

`tiny-library/` and `qwen-library/` retain the twelve accepted records from each
final two-iteration execution. Each contains the immutable foundation, index,
Lean toolchain pin, content-addressed records, and original admission source/log
receipts. These are small checked example datasets, not mathematical discoveries.

Records from the second iteration invoke earlier accepted lemmas. The recorded
curriculum feedback differs between runs because the recipients differ. Read a
library through `VerifiedLibrary(path)`: it checks hashes and performs a fresh
Lean replay. Raw activations, maps, and initial/per-iteration recipient
checkpoints are in the release evidence bundle under their original ignored
`runs/` paths.

The new controlled renderings have agent review. The earlier human approval
applies to the original baseline audit, not these new examples.
